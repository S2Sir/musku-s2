💬 Daily Use — Kaise Baat Karein

  • Voice (Live): Center me START → Mic Allow → bolo — Hinglish / Hindi / English. Beech me rokna ho to "Ruko" bolo.
  • Chat: Bottom bar → CHAT → type karo, Enter dabao. Voice aur chat dono ka history save hota hai.
  • History: Bottom bar → HISTORY → calendar se din choose karo, purani baatein dekho.
  • Theme & Border: Top-right Profile icon (M) → Theme (12) / Border Design (17) → pasand ka lagao.
  • Language: Profile → Language → Hinglish / Hindi / English. "Hindi me bolo" bolke bhi switch hota hai.
  • YouTube / Apps: "YouTube kholo", "Gaana chalao", "Notepad kholo" — bolo, MUSKU kar degi.

⚠️ Dhyaan Do — Data & Privacy

  • Browser ka Clear Data / Clear Cache karoge to MUSKU ke chats, plan, FREE-S2 record sab delete ho jayega.
  • Ek hi FREE-S2 dobara use nahi — block ho jayega. Naya ID chahiye to Code change karo (Pro me convert).
  • Mic ko Windows Settings → Privacy → Microphone me block mat karo.
  • Plan sirf isi browser me save hota hai (localStorage) — dusre browser/phone me alag se activate karna hoga.

🛠️ Problem? Quick Fix

  • MUSKU nahi khul rahi, Plans pe bhej rahi? → Check karo Plan Active Free hai ya nahi. Pro / Expired hai to Plans pe hi rahegi (Only Free loads).

  • API Key error? → Key sahi copy hui? AIza... se start honi chahiye. Profile me dobara paste karo.
  • Pay Now dabane se kuch nahi? → Ye normal hai — Work in Progress popup hi ayega. Abhi sirf FREE-S2 use karo.
